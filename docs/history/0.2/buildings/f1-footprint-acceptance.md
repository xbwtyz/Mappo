# Mappo 0.2F / F1 — Footprint primitives acceptance

> **Status (2026-11-20):** F1 feature implementation is staged on `feature/mappo-0.2f-f1-footprint-primitives`, for review. Planning PR #67 was separately approved and merged. **No F1 implementation merge, tag, schema change, public release, or publication is authorized by this report.** Latest-head permanent CI must pass first.

## Completed F1 foundation

- Added **pure** `src/core/building-footprint-f1.js`: exterior and courtyard vertex insertion, relocation, removal; connected rectangular exterior wing; inward notch producing a U-like footprint; rectangular courtyard add and removal; a shared shape checker that calls the existing `shapeWellFormed`, `shapeContained` and `shapesOverlapInterior`.
- All inputs and rings are cloned. An invalid edit throws without changing the accepted source; valid edits return `{footprint,holes,area}`, using existing schema-9 point arrays.
- Shapes have **one exterior ring plus zero or more holes**; an attached wing is integrated into the exterior ring, not stored as a distinct building entity. A U example uses an inward notch, not a new roof or architectural object.
- No additional persisted building attributes, no schema migration, no duplicate editor, no replacement of current `rectangle` / `L` / `T` / `courtyard` presets.
- The F1 primitives are intentionally **not yet user-facing**: F2 will connect them to existing `BuildingEditSession`, map/Inspector UI, and full project validation/reconciliation. This PR **does not** claim direct click/drag editing, compound edit history, independent access validation, or new selectable presets.

## Focused tests and build

- `tests/building-footprint-f1.test.js` covers cloned mutation, vertex and edge operations, wing and U-shape geometry, courtyard net area and invalid overlaps, degenerate/invalid input, and schema-9 round-trip of generated building records across planned, organic, radial and linear morphologies. It also validates the existing four 3H presets.
- Temporary [focused GitHub CI run #44834324638](https://github.com/xbwtyz/Mappo/actions/runs/44834324638) passed the F1 primitives and existing building regression suite, followed by `npm run build`.
- Root `index.html` and `dist/mappo-0.2-dev.f1.html` were generated by the existing compiler and verified byte-identical at Git blob SHA `761312dc914e2703fe7624f03ec1b81618d07c4b`.
- Temporary workflow removed after successful compilation. **Full permanent Node and Chromium/Firefox CI on the final PR head must still pass**, including legacy building editing.

## Explicitly deferred to F2 and later

- F2: actual vertex and edge handles, direct touch/mouse/keyboard/numeric manipulation, preview/apply/undo integration, access route and plot occupancy reconciliation, and *explicit* consent for replacing custom geometry with a standard preset. Existing 3H replacement can fall back to a rectangle for unknown shapes; **F1 has not yet changed that behavior**.
- F3: independent use/type editing and its metadata-history policy.
- F4: cross-editor property/plot/road QA, comprehensive performance measurements, full browser compatibility and 0.2F milestone acceptance.
- The acceptance plan's first F2 implementation must verify unknown legacy shape labels are **not** implicitly coerced before enabling destructive geometry replacement.
