# Mappo 0.2.0 — 2D City Designer

**Official stable release:** [Mappo v0.2.0](https://github.com/xbwtyz/Mappo/releases/tag/v0.2.0), published November 21, 2026 with the standalone `mappo-0.2.0.html`. Pages is a separate manual deployment and may show a different version.

Mappo is an offline-first medieval/fantasy city generator and 2D editor. This release expands the 0.1 editor from modifying generated details into a more fully editable city designer, while keeping one self-contained HTML distribution and preserving authored work through validated changes.

## What's new since 0.1.0

### Edit streets and let the surrounding city adapt

- Select roads and junctions, preview proposed movement and connection changes, inspect the impact on parcels and buildings, and apply only after an independent fresh validation.
- Generated, untouched neighborhoods can be reconciled locally where safe; existing customized buildings, properties, and other protected geometry are not silently deleted or reattached.
- Invalid or conflicting proposals explain blockers. Canceling a preview retains the accepted city; supported edits use atomic commits and scoped Undo/Redo.
- Large junction previews and main-path Apply validation run expensive work in a bundled background Web Worker, with stale-draft cancellation and current-revision checks. Computation is not instantaneous, but the original roughly one-second synchronous Firefox freeze was addressed.

### Reshape land and buildings

- Create properties, split them with a frontage-to-rear division, merge supported neighboring properties, and adjust plot counts with validated plot ownership and building preservation.
- Modify building footprints with transform, vertices and edges, add wings, cut supported courtyard holes, and edit building identities and use classifications.
- Land/building tools preserve known authored IDs and reject ambiguous lineage or unsafe geometry instead of assuming it is safe to regenerate.

### A focused desktop workspace

- **Generation**, **Add**, and **Roads** are the three canonical workspace tabs. A shared property-first Inspector holds the relevant context and edit controls.
- Dedicated impact review, accepted-versus-proposed comparisons on wide screens, consistent preview/draft/apply controls and faster navigation reduce the need to interpret technical engine reports.
- Tested in Chromium and Firefox on laptop, desktop, and ultrawide viewports, with mouse, trackpad and keyboard input.

### Save, recovery and offline operation

- Download portable `.mappo.json` project files and reopen them; the complete accepted city and supported workspace state round-trip without rebuilding the map.
- Historical project schemas **1–8** migrate to current project schema **9** in memory. Portable envelope format remains **1**; invalid or newer unsupported saves are rejected before replacing the active city.
- Browser-local **latest** and **previous** recovery snapshots survive a page reload and are restored only after explicit user choice. **Portable downloads remain the recommended backup.**
- Distribution is a single self-contained `mappo-0.2.0.html` with no external runtime dependencies or online services.

## Getting started or upgrading

1. Save a separate `.mappo.json` backup of any important work in the existing Mappo version.
2. Download the published [GitHub Release asset `mappo-0.2.0.html`](https://github.com/xbwtyz/Mappo/releases/download/v0.2.0/mappo-0.2.0.html) and open it in a supported desktop browser. No installation or web server is required.
3. Open your saved project from the **Project** menu. Check its properties/buildings and save a fresh portable copy after editing. Project data written with new 0.2 capabilities may not be editable in old builds; keep your original backup.
4. To change a street, use **Roads** and review the candidate's impacts before applying. Use **Add** for new sites and buildings, or select existing properties/buildings to edit them in the Inspector.

**GitHub Pages:** the hosted site is updated only by its own *manual* deployment workflow. A GitHub Release does not automatically publish the website, and the Pages version may differ from the newly tagged release.

## Compatibility and known limitations

- **App:** `0.2.0` · **project schema:** `9` · **project file envelope:** `1`.
- **Supported QA targets:** Chromium and Firefox desktop/laptop with mouse, trackpad or keyboard. Responsive phone/touch acceptance is not part of this release.
- **[Issue #79](https://github.com/xbwtyz/Mappo/issues/79):** road deletion cannot yet create a connected dead end. This requires future graph/parcel engine support and was explicitly deferred beyond 0.2.0.
- Large Organic road preview readiness can still take roughly **0.9–1.0 seconds** on CI hardware; occasional **~100–183 ms frame hitches** remain. This is not the original ~1-second UI freeze. If a reproducible user-facing stall appears, profile that case rather than optimizing benchmark numbers without a diagnosed cause.
- With unavailable workers, some junction fallback paths and ordinary road editing may still perform synchronous validation.
- Not included: a 3D city editor, civic-site additions, arbitrary unrestricted topology, or forced guided onboarding. Editing remains subject to protected-geometry and topology rules.
- Undo/Redo histories and unfinished previews are generally session-scoped and not the same as a permanent version-control history. Download projects to preserve distinct milestones.
