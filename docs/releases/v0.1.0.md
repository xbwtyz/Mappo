# Mappo 0.1.0 — First stable release

**Mappo 0.1** is the first stable milestone of the offline-first 2D medieval city generator/editor.

**Play online:** https://xbwtyz.github.io/Mappo/

**Download:** `mappo-0.1.0.html` — one self-contained HTML file, works locally without installing software or requiring an internet connection.

## Highlights

- Generate deterministic cities with radial, organic, linear or planned streets, configurable city outlines, main square, parcels and individual building footprints.
- Design rivers, coastlines, lakes and mountains; manage district boundaries, names/colors, walls, gates and towers.
- Select properties first; inspect and customize property/building identities.
- Safely edit four-corner property boundaries and plot dividers with non-destructive previews and full validation.
- Add, replace, move, rotate, resize or remove buildings with validation, and clear all buildings from a property in one confirmed operation.
- Delete properties with confirmation, and use session-scoped Undo/Redo for applicable accepted edits.
- Live measurements, precise nudge increments, keyboard shortcuts, contextual warnings and responsive map/Inspector.
- Four layer visibility presets, optional custom download names and a PNG of the visible map view.
- Portable `.mappo.json` saves, save-data migrations from supported historical project versions, and browser-local recovery.

## Installation and use

Open the downloadable HTML file in a modern browser, or visit the hosted Pages site. No additional assets, runtime dependencies or API keys are required for the standalone file. The city data is yours to save locally via **Project → Download project**; browser recovery is an additional convenience, not a substitute for backups.

## Compatibility and scope

- **Application version:** `0.1.0`
- **Project data schema:** `9` (unchanged from Dev 4); compatible historical saves still migrate through supported versions.
- Earlier `dist/mappo-0.1-dev.*.html` snapshots remain available without renaming.
- Undo/Redo history and editing previews are session-only and not serialized.
- Manual road editing, property split/merge, arbitrary concave properties and 3D visualization remain future goals.
- PNG export is a snapshot of the current viewport, not an offscreen full-map tile renderer.

## Testing and reproducibility

The stable distribution is built from modular source, and `index.html` is byte-for-byte identical to `dist/mappo-0.1.0.html`. GitHub CI verifies source compilation, Node regression, portable saves and real Chromium/Firefox browser tests. GitHub Pages deploys the stable root HTML automatically from `main`.
