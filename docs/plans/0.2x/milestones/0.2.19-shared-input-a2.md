## Implementation
Runtime registry resolves active domain contexts; existing domain owners still implement activation, validation and accepted transactions. Capture direct editor callbacks or the transform tool ID at pointer-down; later movement and completion route to that owner. Cancellation clears capture before calling the domain, and runs before workspace teardown, road exit, project replacement and confirmed editor exit. Escape cancels captured gestures first. Ordered global input dispatch routes existing commands, save and Space. Local menu/ARIA controls retain precedence. Comparison remains pan-only. Existing tap/hover and form-specific handlers remain domain adapters; further inspector and lifecycle UI integration belongs to A3/A4. No group writes or new persistence.

## Gates
P1 registry priority, eligibility and leave tests. P2 owner stability, cancelled and late events; browser Escape and Space pan. P3 ordered commands and focus protection. P4 existing editor and A1 regression, history and persistence. P5 exact-head fast/full CI, deterministic standalone parity, offline Firefox/Chromium. Existing tests remain required. Manual workflow benchmarks remain outstanding.
