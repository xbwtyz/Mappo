# 0.2.21-dev A4 — Shared draft lifecycle and diagnostics

Owner-approved A4-01=B and A4-02 through A4-10=A. The shared runtime draft engine governs session identity, accepted-city baseline, draft and validation revisions, pending state, discard/reset, diagnostics, and Apply eligibility. Domain editors prepare geometry and accepted transactions using their existing rules.

| Decision | Contract |
| --- | --- |
| A4-01=B | One authoritative draft engine with one interactive editing session and independent staged settings. |
| A4-02=A | Shared lifecycle and Apply, Reset, and Cancel semantics. |
| A4-03=A | Preserve original diagnostic codes, reasons, affected records, severity, and available remedies. |
| A4-04=A | Integrate editors incrementally through their current controls and entry points. |
| A4-05=A | Explain blocked edits and offer existing corrective or locate actions where supported. |
| A4-06=A | Bind validation evidence and asynchronous Apply to the live session and revision. |
| A4-07=A | Preserve drafts on declined discard and presentation-only navigation. |
| A4-08=A | Preserve geometry validation, explicit domain decisions, and atomic accepted transactions. |
| A4-09=A | Retain Undo/Redo, recovery, established regression coverage, and six CI runners. |
| A4-10=A | Schema 10, portable envelope 1 and workspace version 1. Persist existing workspace settings in their existing representation. |

## Implementation checkpoints and acceptance

| Checkpoint | Implementation | Acceptance |
| --- | --- | --- |
| P1 | Shared draft engine, normalized diagnostics and control projection | One interactive owner. Clean, pending, checking, valid, blocked, stale, applying and inactive states have distinct eligibility. Warnings can accompany Apply. Unresolved decisions block it. Declined discard preserves the same draft revision. |
| P2 | Building, component, courtyard, compound and property/plot adapters | Existing direct and structural controls submit fresh validation through their domain transaction. A blocked edit leaves accepted city and Undo/Redo unchanged. Locate changes only the map camera. |
| P3 | Road/junction adapter and worker revision binding | Reset, Cancel, new preview inputs or replacement invalidate old evidence. The worker result matches the current draft identity and intent revision before it can enable Apply. Group inspection remains read-only and road-specific reconciliation and comparison remain available. |
| P4 | Staged generation, landscape, districts, defenses and identity | Landscape and district settings survive existing navigation and workspace restore. A declined rebuild preserves the generation preview. Failed rebuild validation preserves accepted geometry and staged landscape inputs. District and defense operations keep their existing local validation and history. |
| P5 | Focused Node tests and two offline browser scripts | Run both Node shards and all 35 browser scripts through the six runners. Verify Chromium, Firefox, exact-head CI and byte-for-byte standalone parity. Owner hands-on acceptance is separate. |

Generation review uses the same live controls as before. Changing its inputs invalidates a reviewed candidate. Rebuild is explicit and performs fresh generation against detached inputs before replacing the accepted city or updating the landscape draft. Existing save and recovery continue to capture existing workspace settings. The shared engine is runtime-only.
