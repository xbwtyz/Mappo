## P1–P5

P2 place host adds read-only Details while retaining the original six live panels, status/actions, property-first selection and existing management operations. P3 road host exposes Details/Edit/Review and A1 group summary; existing reconciliation, dock, comparison and footer remain domain-owned. P4 landscape and district hosts reuse the same contract and existing generation/creation/rebuild semantics. P5 targeted Node checks, offline browser script in integration (33 total), full existing suites, exact-head CI and deterministic standalone parity.

View switching is presentation only; existing leave gates, validation, accepted transactions, draft protection, editor handlers and save/recovery remain authoritative. Specialized hosts remain physically separate, coordinated through the shared presentation controller. Selection quick actions are retained as entry points into existing edit hosts. No forced review step. Group movement, expanded selection, generic transforms, draft/diagnostic overhaul and history consolidation are out of scope. Building compounds retain their existing management panel. The compact fallback remains supported.
