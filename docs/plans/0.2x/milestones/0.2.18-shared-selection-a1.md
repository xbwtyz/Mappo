## Contract and first integration
- Immutable ordered stable-ID references, deterministic primary, duplicate/mixed-kind rejection, 256 reference bound, explicit replace/toggle/clear/reconcile. No accepted geometry mutation or history entry.
- The workspace owns the runtime selection set; ordinary existing inspectors consume the singleton projection. The road session uses the same set through a transient adapter; legacy road operations receive only a singleton. The existing saved workspace snapshot remains authoritative for the transient road visit.
- Initial live grouping is road segments only. Other existing domain selectors remain singleton through the same model; group interactions for them require later capability integration. Junctions are singleton. Groups may be disconnected; Phase B will define connected graph transformations.
- Shift-click toggles road membership; plain map tap replaces; empty map clears; group Escape clears with map focus. Existing singleton road-workspace Escape exit behavior is retained. Merge/bend gestures retain priority. A pending road draft blocks retargeting via map or record controls; Reset/Cancel remain available.
- Group road inspector shows count, primary, removable members, locate and clear. All geometry writes are disabled for groups. Road highlights distinguish primary and secondary members. This does not implement movement, box selection, mixed selections or new geometry.
- No persisted group, schema change, CI policy or new dependency.

## P1–P5 review gates

P3 modifier gestures, active-draft priority, group rendering, stale project guard. P4 read-only group summary, remove, locate and clear. P5 targeted Node and offline Firefox/Chromium browser tests, full exact-head CI and deterministic standalone parity. Do not interpret authored tests as passed before CI completes.
