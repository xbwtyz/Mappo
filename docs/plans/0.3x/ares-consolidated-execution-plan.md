## Data flow and authority
Accepted city + revision + exact intent + mode/permissions -> typed operation snapshot -> UAEF coordinator -> observable/writable/protected scope + constraint providers -> registered serial strategies (later qualified worker pool) -> RTRE geometry/topology, face/ownership reconciliation and SRE recovery -> independent domain candidate verification -> deterministic ranked incumbent/alternatives -> host-owned Review/Apply token -> fresh independent verification and allocation -> atomic accepted-city transaction -> scoped Undo/Redo, portable persistence, derived rendering. Feedback consists of verified blockers and bounded proposals only. Each boundary carries versioned typed refs, provenance, capability flags, evidence, work/budget and cancellation/stale identity. Workers/providers cannot publish or expand authority. Hard safety, exact selected position, protected anchors and explicit permissions precede scoring. No implicit landscape changes, new intersections in Adaptive, automatic demolition, budget multiplication or silent fallback to altered intent. Preserve existing SRE and Strict behavior as qualified reference/fallback for supported intents. Use current validators and modular offline HTML build; derive indexes/caches from accepted revision, not a second authoritative city.

## Qualification protocol
Freeze independently constructed feasibility witnesses (exact intent, valid candidate, correct permissions, independent validators), stable fixture manifest, movement size definitions and counts, held-out seed set and metric rules before final qualification. Minimum 10,000 unique topology/recovery scenarios; report probe versus full solve separately, no counting duplicate repetitions as new scenarios. Include all morphologies, small/moderate/large city/density, 2/3/4/5/8+ connected segments, quadrilateral/pentagon/branch/loop/tail, axes/diagonals ±1/10/25/50/75/100, independently feasible 100-unit references, regular/irregular development, protected/author-created content, dry and mixed river/lake/coast/terrain/crossings with valid/invalid controls, repeated history and portable reopen. Unsupported real combinations and synthetic vertical constraints separately reported; no false live capability or rate inflation. Freeze nonempty meaningful denominators before final tests and disclose attempted totals, eligibility, invalid/unsupported/permission/scope limits, exhausted and unverified outcomes. Existing minimum independently feasible recovery: small 99%, moderate 95%, large 90%, topology restructure 85%. Definitions and allocations must be predeclared and reviewed, not fitted to results. Report overlapping strata clearly, no double counting in overall denominators, no post-hoc exclusions. Compare W4 baseline and serial portfolio at matched work; compare worker counts at matched portfolio/budget; measure first verified incumbent, final reviewed candidate, preservation and cost, work, memory, transport overhead, frame/pointer responsiveness, Stop/Continue and cancellation. Set numeric limits during controlled research and review before activation, not retroactively; no unsupported speed guarantees. Parallel and multi-candidate default only after parity, benefit and resource qualification. Keep 0 invalid accepted cities, 0 unauthorized mutations/data loss, 0 stale publications, 100% successful edits reversible, all existing regression and CI coverage. Missed targets remain blockers; no unilateral relaxation.
