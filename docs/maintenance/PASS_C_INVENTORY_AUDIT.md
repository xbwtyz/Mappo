## Impact / dependency audit

- **Code and tests:** All 38 `tests/**/*.js` modules were searched for literal `dist/` or versioned output paths. `tests/phase7-control-inventory.test.js` explicitly references `dist/mappo-0.1-dev.3e6.html`; `tests/build.test.js` uses the dynamically current versioned distribution. The nine `tests/fixtures/` frozen save files are separate compatibility evidence and must be retained.
- **Documentation:** All 37 tracked Markdown documents were inspected for versioned HTML references. References exist in the current README/guides, milestone 3F records, the archived README, and legacy QA. Historical examples include `3fa`, `3faa`, `3fb`, `3fc`, `3fd`, `3e4`, `ui4b`, `ui4c`, and `ui5d`; these are not safe to remove without dedicated link review.
- **Known historic caveat:** The archived detailed README identifies `0.1-dev.3a1` as an older advanced-shape snapshot with unresolved crossings, not the current validated build. It remains a historical artifact; this audit does not retest or certify it.
- **Pages:** `.github/workflows/pages.yml` still publishes `index.html` and `dist/` from `main` and asserts at least **26** distribution HTML files. It is intentionally unchanged (C6 denied).
- **Archive comparison:** The archive matches the exact main commit, every distribution blob SHA, the Pages workflow, and `index.html`, and retains the same nine compatibility fixtures. A branch is a Git reference: avoiding later movement/deletion of `archive/pre-3g-history` is necessary for long-term preservation.
